# GlossQuote-Labs 品牌與產品原則

版本：1.0。定位草案已轉為本批工具的開發基線；工具尚未實作。

## 品牌定位

**GlossQuote-Labs：為日常問題，製作好用的工具。**

品牌涵蓋文字、資料、設計、計算、規劃、時間管理、開發與影音；不把品牌限制成轉檔站。共同特色是打開網站即可開始、任務清楚、以使用者裝置運算、尊重資料、結果可取得。這是產品方向，不代表現有工具都已完成或通過驗證。

- 對外品牌名稱固定為 GlossQuote-Labs，大小寫與連字號不變。
- 每款工具的主標題用具體中文工作名稱；英文 slug 只用於程式與未來網址。
- 不為每個工具再發明一個讓人猜功能的子品牌。
- 設計系統快照內的「Gloss Tools by GlossQuote」是原始文件來源名稱；本批對外顯示使用 GlossQuote-Labs，不複製舊品牌文案。
- 每個工具都有自己的工作布局，不強制使用同一款側邊欄或卡片首頁。

## 使用者承諾與證據

| 原則 | 實作要求 | 可用於對外宣稱的前提 |
|---|---|---|
| 本機處理 | 使用者內容在瀏覽器內處理，無上傳 API | 實際網路與程式路徑驗證 |
| 容易開始 | MVP 無帳號、安裝或付費門檻 | 完整匿名流程通過 |
| 結果可取 | 複製或下載輸出；失敗有恢復途徑 | 各工具驗收案例通過 |
| 誠實呈現 | 格式、上限、精度、模型誤差先說明 | 與實際實作一致 |
| 能自行控制 | 清除、取消、編輯在需要時可見 | 競態與清理驗證 |
| 可長期維護 | 小範圍、固定版本、離線假資料測試 | 不把未來功能塞進 MVP |

不宣稱「所有檔案都支援」「100% 安全」「絕不出錯」「保證辨識準確」「永遠免費」「一定排名第一」。MVP 不做收費，不代表替品牌承諾永久商業模式。

## 介面語言

繁體中文 zh-Hant 為第一版。短句、具體動詞、結果導向：選擇檔案、開始比較、下載圖片、清除內容。錯誤說明發生什麼和可以怎麼處理；不用原始 stack trace、內部 API 名稱或責怪使用者的語句。

不要讓第一次訪客先閱讀品牌宣言才開始操作。主工作區放前面，操作方式、限制、FAQ 接在後面。桌面與手機都保留完成同一任務的途徑。

## 品牌辨識

沿用 [設計系統](DESIGN-SYSTEM.md) 的暖紙色、深墨色、酸綠主動作、語意色、字級與間距 token。第一版用系統字型 fallback；不下載遠端字型。不新增裝飾動畫、假使用者數、見證或徽章。

參照 UI/UX Pro Max 技能的無障礙、觸控回饋、資訊層級原則做規格檢查；沒有執行該技能的外部程式，也沒有採用它產生的新品牌系統。本地設計與安全契約優先。

## 網站內容與 SEO

每個工具提供獨有 title、description、H1、操作教學、限制與 FAQ，文字需存在初始 HTML。搜尋詞只是描述任務的假說，沒有搜尋量或競爭度調查。不要用程式生成數百個同義詞頁面。

本機預覽用 noindex。正式網址尚未選定，不填假網域 canonical，不送 sitemap，不接 Search Console 或追蹤服務。收到發布要求後再驗證網址、移除預覽索引限制並完成發布清單。

本頁是可獨立攜帶的品牌規範，不需要讀父專案。
