# CSV 工作表介面

2026-10-10；Product App。對象是持有小型 CSV、需要確認原始字串並保留幾欄的使用者。成功狀態是看得見所選欄、公式風險與修改對照，主動下載正確格式。輸入資料不可信，尤其是格值公式與 HTML。

沿用家族語意色：ink #111410、paper #f3f0e8、surface #ffffff、acid #c8f56a、muted #55594f、warning #713f00。UI 使用 Segoe UI／system-ui，資料使用 Cascadia Mono／ui-monospace；沒有字型下載。採平面工作表，綠色只強調當前預覽／下載動作，不加入行銷 hero、樣本假資料或卡片牆。

Always-visible 是來源、預覽、表頭、清除；相鄰功能是選欄、表格分頁、匯出格式；匯出準備後才出現對照／確認。風險原因與可用原值 JSON 出口在格式旁。來源 textarea 高度有限，已預覽資料表可佔完整寬度。

```text
桌面：品牌／同語言首頁／語言／清除
      來源檔案、文字、預覽與表頭
      選欄 → 大型原值表格 → 分頁
      風險／格式／準備 → 原值与保護值並排對照 → 確認／下載
      方法、限制、六個 FAQ

手機：相同流程單欄；選欄可換行
      表格只在具名區域內水平捲動
      對照上下排列；確認及下載留在內容流程
```

使用共享 48rem／75rem breakpoint、44px 主要目標、雙層焦點與 reduced-motion。沒有拖曳或隱藏核心功能。長值完整保存，局部可捲動，欄位重建保留焦點。格式／來源／表頭／選欄每次變更均撤銷輸出與確認。

SEO 預設來源 noindex；release 參數只準備指定 csv.glossquote.com 的候選，不宣稱已上線。兩語都是靜態 HTML 方法與 FAQ，兩語資料處理功能相同。視覺與功能證據見 VALIDATION.md；不再進行無限制的視覺探索。
