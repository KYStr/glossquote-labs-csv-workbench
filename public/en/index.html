How to inspect and organize CSV columns

Load a small comma-separated CSV, check column names and data, then choose the columns to keep. This tool does not infer numbers or dates, or execute formulas.

  1. Paste CSV text or explicitly choose one UTF-8 .csv file.
  2. Select “Preview CSV”, check whether the first record contains column names, and choose the columns to keep.
  3. To locate a cell, choose a kept column and literal text, select “Find” and move between matches across pages. Search does not reduce the exported data.
  4. Choose an export type and select “Prepare export”. Review changes in the protected copy, acknowledge them when required, then select “Download copy”.

Format and preservation

Only UTF-8 CSV with commas, double-quote escaping and consistent column counts is accepted. Record separators may be CRLF or LF; a lone CR outside quotes is rejected. Big5, UTF-16 and separator detection are not supported. Missing columns are not filled. Cell editing and sorting are not available.

Exported CSV quotes every cell, separates records with CRLF and uses UTF-8 without a BOM or a final record separator. Line breaks inside cells depend on the source path. “Original values” preserves cell strings and the order of selected columns and records, not the file’s original bytes. JSON uses schemaVersion 1 with source column positions and complete arrays of record strings.

Conservative formula-risk rules include =, +, -, @ and their fullwidth equivalents after leading whitespace, or leading Tab, CR or LF. Negative numbers such as -12 are also flagged. CSV structure quotes do not protect against formulas. Prefixing an apostrophe in the protected copy changes the value. Original CSV is disabled when selected cells have risk; original JSON remains available.

Frequently asked questions

Will 001 become 1?

No. Cell values remain strings throughout this tool. Other software may infer types when opening downloaded CSV. Check its import settings.

Why can’t my CSV be read?

This tool accepts only valid UTF-8, comma-separated CSV with complete quote syntax and consistent column counts. Convert Big5, semicolon-separated or Tab-separated files in their original application first.

How does the protected copy differ from original values?

The protected copy adds an apostrophe before possible formula values, changing those cell strings. Original JSON keeps complete strings. Original CSV cannot be exported when selected cells have risk.

Does the protected copy guarantee spreadsheet safety?

No. Applications and subsequent saves may handle values differently. Check the content and do not treat text in an unknown CSV as trusted formulas.

Can I edit, sort or upload Excel files?

This tool only previews CSV and selects columns. It does not edit values, sort, accept xlsx or send data to cloud processing.

Will line breaks inside my file change?

When a selected file is not edited, line breaks inside cells are preserved from the original file text. Pasted or edited sources use the browser text field’s LF line breaks. To preserve original CRLF inside cells, choose the file again and preview it directly.

Data and network

After the website’s HTML, JavaScript and styles load, CSV parsing and export run in your device’s memory without a processing server, accounts or content storage. The website host may still receive connection information for ordinary static resource requests. There is no tracking, remote font or cloud fallback.
